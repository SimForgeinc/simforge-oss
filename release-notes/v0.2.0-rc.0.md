# simforge 0.2.0-rc.0 (DRY RUN 2 on main, not published)

Dry run of the release pipeline on simforge-sdk main 133ba00d (#24 release pipeline,
#64 sky path, #65 rc-readable smoke fixture + golden, #66 open files), with the
rc.0 version bumps applied locally. Nothing was tagged, pushed, signed publicly
or published.

The first release of the Rust `simforge` CLI: scenario packages exported from
the hosted app, maps and actor assets by digest, the deterministic renderer
(training and showcase presets), re-simulation, closed-loop episodes over a
socket, the authoring commands, and agent skills. Engine 0.12.1.
