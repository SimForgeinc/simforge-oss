SimForge

Choose a connection

    Pair with a remote host

    On the host machine run simforge host pair. Paste the simforge://connect link it prints, or the host's address and the code. The code is exchanged once for the host's credentials, which are kept in this computer's credential vault.

    Choosing another connection relaunches SimForge Studio: the window, its session and its menus are built for one host at startup.

    Switching later relaunches SimForge Studio (Connection › Switch Connection…).
