# SimForge Studio desktop previews: discontinued

The desktop builds of SimForge Studio (`studio-preview.*` releases of this
repository) are discontinued and will not be updated. The published installers
stay downloadable from the Releases page, unchanged, but receive no fixes.

- SimForge Studio is available hosted at https://simforge.ai.
- The engine, renderer, CLI and Python gym live on in this repository (renamed
  from `simforge-oss` to `simforge-sdk`; old links redirect).
- The Studio and TypeScript sources that used to be here remain in this
  repository's history.
