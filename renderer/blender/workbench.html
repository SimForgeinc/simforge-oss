Edits run in a disposable confined Blender worker. Supported inert geometry is imported and rendered atomically; unsupported semantics fail closed. Failed edits roll back. Undo and redo restore geometry snapshots, not just images.

        

        

      

      
Geometry is not simulation truth
Visual geometry and materials only. These edits do not update SimForge physics, road rules, or NuRec splats. Original source meshes and textures remain unchanged.
Local isolated worker
Worker code has no networking and can read only its snapshot and runtime; writes stay in per-job output. Only inert data enters the renderer. Linux Landlock and seccomp are required. This is not a VM or protection against native Blender/kernel vulnerabilities. Keep the trusted HTTP service loopback-only.
